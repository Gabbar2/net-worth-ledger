Data & privacy

Holdings, orders, salary/expense entries, and manual income are stored only in this browser's local storage for this file. Your Binance/OKX API keys never touch this page or your browser at all — they live either in proxy-config.json next to the local proxy script on your own computer, or as encrypted environment variables on a cloud proxy deployment you control (e.g. Vercel). Either way, this page only ever talks to the proxy URL you set below — it never sees your keys. Because browser local storage isn't guaranteed to survive cleanups, export a backup occasionally.

PKR floats, so update this rate yourself whenever you want a fresher conversion — AED is pegged to the dollar and rarely moves.

If your Binance/OKX proxy URL above points at localhost, leave this blank. If it points at a deployment you put on the internet (e.g. Vercel), set this to the same value as that deployment's PROXY_ACCESS_TOKEN environment variable — without it, every request there is refused. This token is stored only in this browser's local storage; it never leaves your device except as a header sent to the proxy URL you configured above.
